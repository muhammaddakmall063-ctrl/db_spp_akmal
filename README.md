# db_spp_akmal
Aplikasi SPP Online SMK Negeri 3 Banjarbaru. Halaman login (index.php) memvalidasi petugas lewat login_validasi.php, lalu mengarahkan admin dan petugas ke dashboard masing-masing. Siswa atau orang tua bisa cek riwayat pembayaran SPP tanpa login lewat NISN di bayar.php. Kelemahan utama: SQL injection, MD5, dan tanpa escape output.
